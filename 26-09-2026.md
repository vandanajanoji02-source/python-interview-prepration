# Python Interview Preparation Questions and Answers

1. What is Python?
   Answer: Python is a high-level, interpreted, and general-purpose programming language known for its simple syntax, readability, and versatility. It is widely used in web development, automation, data science, AI, scripting, and backend development.

2. What are the features of Python?
   Answer: Python has several important features:
   - Easy to learn and read
   - Interpreted language
   - Dynamically typed
   - Object-oriented and functional support
   - Large standard library
   - Cross-platform compatibility
   - Strong community support
   - Easy integration with other languages

3. What are the advantages and disadvantages of Python?
   Answer:
   Advantages:
   - Simple and readable syntax
   - Fast development
   - Huge library support
   - Good for beginners
   - Used in many fields

   Disadvantages:
   - Slower than compiled languages like C/C++
   - Not ideal for mobile app development
   - Runtime errors can appear during execution
   - Memory consumption can be higher in some cases

11. How does Python work internally?
   Answer: Python code is first written by the developer and then executed by the Python interpreter. The interpreter reads the source code, converts it into bytecode, and then executes it using the Python Virtual Machine (PVM). Python also uses memory management and garbage collection internally.

12. Explain Python architecture.
   Answer: Python architecture includes:
   - Source code written by the developer
   - Python compiler that converts source code into bytecode
   - Python Virtual Machine (PVM) that executes bytecode
   - Standard library and built-in modules
   - Memory manager and garbage collector

13. What is indentation in Python, and why is it used instead of semicolons or braces?
   Answer: Indentation is the spaces or tabs used at the start of a line to define code blocks. Python uses indentation to mark blocks such as loops, conditions, and functions. This improves readability and enforces consistent structure. Unlike languages like C, Java, or C++, Python does not use braces or semicolons to define blocks.

15. What are variables in Python, and how do they differ from other programming languages?
   Answer: Variables are containers used to store data values. In Python, variables are dynamically typed, meaning you do not need to declare the type explicitly. Example:
   ```python
   name = "Alice"
   age = 25
   ```
   Unlike some languages such as Java or C++, Python does not require variable type declarations.

16. What are data types in Python, and how do they differ from other backend programming languages?
   Answer: Data types define the type of value stored in a variable. Python has built-in data types such as:
   - int
   - float
   - str
   - bool
   - list
   - tuple
   - set
   - dict

   Python is dynamically typed, so the type is inferred automatically. In many backend languages, data types are often declared explicitly and may be stricter.

17. What are functions in Python, and how do they differ from other backend programming languages?
   Answer: A function is a reusable block of code that performs a specific task. In Python, functions are defined using the def keyword.

   Example:
   ```python
   def greet(name):
       return "Hello, " + name

   print(greet("Alice"))
   ```

   Python functions are simple, flexible, and support default arguments, keyword arguments, and returning multiple values. Compared to some backend languages, Python is more concise and easier to write.

18. What are the types of functions in Python?
   Answer: The main types of functions in Python are:
   - Built-in functions: predefined functions like print(), len(), type()
   - User-defined functions: created by the programmer
   - Anonymous functions: lambda functions
   - Recursive functions: functions that call themselves
   - Higher-order functions: functions that accept other functions as arguments

19. What are arguments and parameters in Python?
   Answer: Parameters are variables listed in the function definition, while arguments are the actual values passed to the function when it is called.

   Example:
   ```python
   def add(a, b):   # a and b are parameters
       return a + b

   result = add(5, 3)  # 5 and 3 are arguments
   print(result)
   ```

20. What is the difference between parameters and arguments?
   Answer: Parameters are declared in the function definition, while arguments are passed during the function call. Parameters define what the function expects; arguments provide the actual values.

21. What is a lambda function in Python?
   Answer: A lambda function is an anonymous function defined using the lambda keyword. It is usually used for short, one-line operations.

   Example:
   ```python
   square = lambda x: x * x
   print(square(5))
   ```

22. What is the difference between list and tuple in Python?
   Answer: A list is mutable, meaning it can be changed after creation. A tuple is immutable, meaning it cannot be changed once created.

   Example:
   ```python
   my_list = [1, 2, 3]
   my_tuple = (1, 2, 3)
   ```

23. What is a dictionary in Python?
   Answer: A dictionary stores data as key-value pairs. It is unordered, mutable, and very useful for mapping one value to another.

   Example:
   ```python
   student = {"name": "Alice", "age": 22}
   print(student["name"])
   ```

24. What is a set in Python?
   Answer: A set is an unordered collection of unique elements. It is useful when you want to store unique values and perform mathematical set operations.

   Example:
   ```python
   numbers = {1, 2, 2, 3}
   print(numbers)  # {1, 2, 3}
   ```

25. What is the difference between Python and JavaScript?
   Answer: Python is known for readability and data-oriented programming, while JavaScript is primarily used for web browser interaction and frontend development. Python is commonly used in backend, AI, and data science, while JavaScript dominates web development.

26. Why is Python popular for backend development?

28. What is the difference between Python 2 and Python 3?
   Answer: Python 3 is the modern version and is the only actively supported version. Python 2 reached end-of-life and is no longer recommended. Python 3 includes improved syntax, better Unicode support, and many library updates.

29. What is a virtual environment in Python?
   Answer: A virtual environment is an isolated environment that contains its own Python packages and dependencies. It helps avoid conflicts between project dependencies.

   Example:
   ```bash
   python -m venv env
   ```

30. What is pip in Python?
   Answer: pip is the package installer for Python. It is used to install, update, and remove Python packages from the Python Package Index (PyPI).

   Example:
   ```bash
   python -m pip install requests
   ```
